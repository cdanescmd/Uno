# Changelog

## v0.1.0

First public release of Uno, a reusable preflight for AI-assisted web, code, image, and video work.

- Load `UNO.md` once, then describe the change in one line.
- Before acting, Uno checks the current version, looks for an existing setting or reusable component, and chooses the smallest complete change.
- Set limits on reply length, changed code lines, prompt length, or generation attempts.
- Use `Preview only` to review the proposed action or `Prompt only` to get text for a generator.
- Try the worked examples in `EXAMPLES.md`, including a code edit with a two-line budget.

Start with the README. Released under the MIT license.
